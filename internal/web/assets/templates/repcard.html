Operators Running this node on v26? Check one setting

Banano v26 ships with online_weight_minimum set to 2.15B BAN, so the node needs about 1.44B BAN of votes before it confirms anything. If voting weight dips, it stalls while correctly configured nodes carry on. The recommended value is 900M:

grep online_weight_minimum config-node.toml

# if it's missing or not 900M, add under [node]:
online_weight_minimum = "90000000000000000000000000000000000000"

Then restart the node. Nodes don't share their config, so the explorer can't see whether yours is set; this tip shows on every rep page.
